# 📈 Модуль финансовой статистики и прогноза выручки (RF)

Модуль показывает **план**, **прогноз**, **факт**, детализацию по тарифам, метрики удержания/оттока, а также даёт срезы по UTM-меткам и дополнительный дневной прогноз. Ниже — актуальные показатели экранов.

---

## Основной экран (месяц)

### 📅 Текущий месяц
- **🎯 План на начало месяца** — плановая корзина на 1-е число: истечки месяца + подписки, у которых *предыдущая* дата истечения (prev_expiry) попала в этот месяц (могли продлиться заранее).
- **💰 Ожидаемые продления** — прогноз по остаточным истечкам месяца с учётом вероятностей: `Σ (цена × количество × вероятность)`.
- **✅ Факт** — сумма успешных платежей за текущий месяц.
- **📏 Выполнено** — процент выполнения плана (см. режимы ниже).
- **📊 Остаток на сегодня — детализация** — тарифы, которые ещё истекут в текущем месяце (ещё не продлены).

### 📐 Метрики
- **💳 Средний чек** — `Факт / число успешных платежей`.
- **📦 Оплат за месяц** — количество успешных платежей.
- **👥 Активные пользователи** — количество пользователей с активными ключами (пересекаются с текущим окном).
- **🔑 Активных оплаченных ключей** — текущая оплаченная база без учёта тестов/заморозки (зависит от настроек фильтров).
- **📊 ARPU** — средняя выручка на пользователя: `Факт / Активные пользователи`.
- **🔁 MRR (активная база)** — месячная повторяющаяся выручка «на сейчас»: `Σ (цена / месяцев × количество)`.

### 🧲 Удержание и отток
- **🧲 Retention** — доля «клиентов на продление» текущего месяца, которые уже продлились.
- **💔 Churn** — доля клиентов, которые **пока** не продлились.
- **✅ Продлили / ⏳ Ещё не продлили** — абсолютные числа.
- **🔮 Прогноз оттока** — ожидаемое число тех, кто в итоге **не продлит**: `Σ (1 − p_корзины) × count_корзины` по «ещё не продлившим».

### 📢 Реклама и эффективность
Блок показывается, если включён `ENABLE_ADS_BLOCK` и у пользователя есть права на редактирование.
- **📊 Расход за месяц** — введённая сумма рекламных расходов за текущий месяц.
- **👥 Новые клиенты** — сколько пользователей оплатили впервые в текущем месяце.
- **💰 Выручка от новых клиентов** — сумма первых платежей за месяц.
- **CAC** — стоимость привлечения клиента: `Расход / Новые клиенты` (если обе величины > 0).
- **ROI** — `(Новая выручка − Расход) / Расход × 100%` (если расход > 0).

---

## 📆 Дневной прогноз
Отдельный экран «Прогноз по дням» показывает корзину истечек за выбранную дату. Навигация стрелками или кнопкой «Сегодня», детализация — `кол-во × цена` по тарифам.

---

## 🏷️ UTM-аналитика
Постраничный отчёт по UTM-меткам (код/название):
- **Прошлый/текущий месяц** — суммы выручки за месяц, прирост и его знак (∞, если в прошлом месяце было 0 и сейчас > 0).
- **Продлений за весь период** — сумма платежей-продлений по метке.
- **Всего за весь период** — количество успешных платежей и их общая сумма.
- **Реклама и эффективность (по метке)** — месячный расход, новые клиенты, первая выручка, CAC и ROI (если есть данные).

Из карточки метки можно сразу внести расход на рекламу этой метки; кнопка доступна только пользователям с правом редактировать рекламные расходы.


## Режимы расчёта процента «📏 Выполнено»
Выбирается настройкой `COMPLETION_MODE`:
- **plan_vs_forecast (по умолчанию)** — `(План − Прогноз)/План`. Понятно и наглядно: предоплаты прошлого месяца сразу уменьшают Прогноз и считаются выполненными с 1-го числа.
- **accrual** — `Признано по prev_expiry до «сейчас» / План`. Предоплаты признаются в дни плановой истечки.
- **cash** — `Факт / План`. Чисто кассовый подход (1-го числа может быть низко из‑за предоплат 31-го).

Вероятности продления берутся из ручных настроек (`PLAN_PROB_OVERRIDES`, `RENEWAL_PROBABILITY`) или **оцениваются автоматически** по последним 3 месяцам (по корзинам `1m/3m/12m/other`).
