# Инструкция по настройке модуля офлайн‑конверсий Яндекс Метрики

Ниже приведена простая и понятная инструкция по полной настройке модуля.

---

## 1. Что делает модуль

Модуль автоматически отправляет конверсии в Яндекс Метрику:

* получение триала;
* покупка подписки.

Отправка конверсии сработает только если выполнены условия:

1. пользователь перешёл в бота по ссылке вида:

```
https://t.me/<bot>?start=utm_ya_<cid>
```

2. модуль извлёк и сохранил CID;
3. произошло событие триала или покупки.

---

## 2. Что потребуется

Из Яндекс Метрики нужно получить:

* **ID счётчика (tid)**; - При создании счетчика снимаем галочку "Принимать данные только с указанных адресов"
* **Secret key (ms)** для Measurement Protocol.

Эти данные далее прописываются в `settings.py`.

---

## 3. Настройка Яндекс Метрики

### 3.1 Создаём счётчик

Создаём счётчик в Метрике и добавляем код счётчика на сайт по инструкции самой Метрики.

### 3.2 Включаем Measurement Protocol

1. Включаем OAuth‑токен Яндекс Метрики: [https://yandex.ru/dev/metrika/](https://yandex.ru/dev/metrika/) - При включении токена заполняем данные как в примере: https://iimg.su/i/hx73DM
2. Получаем OAuth‑токен Яндекс Метрики: [https://yandex.ru/dev/id/doc/ru/tokens/debug-token](https://yandex.ru/dev/id/doc/ru/tokens/debug-token) - При создании токена заполняем данные как в примере: https://iimg.su/i/hx73DM
3. Включаем Measurement Protocol: [https://yandex.ru/dev/metrika/ru/data-import/manage-protocol#enable-option](https://yandex.ru/dev/metrika/ru/data-import/manage-protocol#enable-option) - Включение протокола путем запроса curl как в документации Яндекса
4. Получаем Secret Key: [https://yandex.ru/dev/metrika/ru/data-import/manage-protocol#gen-tokens](https://yandex.ru/dev/metrika/ru/data-import/manage-protocol#gen-tokens) -  Токен создается путем запроса curl как в документации Яндекса
5. Далее вставляем ID счётчика и Secret Key в `settings.py`:

   * ID счётчика — `YA_TID`;
   * Secret key — `YA_MS`.

---

## 4. Создание целей

### 4.1 Цель: trial‑add

В настройках Метрики переходим: Счётчик → **Цели** → Добавить цель.

Тип: **JavaScript‑событие**

* Название: `Trial (выдан триал)`
* Идентификатор цели: `trial-add`

### 4.2 Цель: purchase

Тип: **JavaScript‑событие**

* Название: `Purchase (оплата подписки)`
* Идентификатор цели: `purchase`

---

## 5. Настройка модуля в проекте

Открыть файл:

```
yandex_offline_conv/settings.py
```

Проверить:

```
ENABLED = True
START_PREFIX = "utm_ya_"  # префикс обязательный, его не меняем

YA_TID = "<ID-счётчика>"
YA_MS = "<secret-key>"
YA_COLLECT_URL = "https://mc.yandex.ru/collect"

YA_DL = "https://t.me/название_бота?start=mp"
YA_DR = "https://yandex.ru"
YA_DT = "Telegram Bot"
```

---

## 6. Настройка UTM‑метки в боте

В админке бота нужно создать отдельную UTM‑метку:

```
utm_ya
```

Эта метка используется модулем для отслеживания.

Важно: если в боте включена обязательная подписка на канал перед стартом, данные по этой метке станут неточными. Метка техническая — корректные данные по конверсиям всегда смотрите в Яндекс Метрике.

---

## 7. Настройка кнопок перехода в бота на сайте

Каждая кнопка, ведущая в бота, должна иметь ссылку:

```
https://t.me/название_бота?start=utm_ya
```

Где `utm_ya` — созданная вами метка.

---

## 8. Добавление ClientID на лендинг

Чтобы ClientID автоматически подставлялся в ссылки бота, вставьте на страницу (ниже кода Метрики) следующий скрипт, не забудьте в нем подставить свои данные:

```html
<script>
  ym(<ID_СЧЁТЧИКА>, 'getClientID', function(clientID) {
    if (!clientID) return;
    const links = document.querySelectorAll('a[href*="t.me/имя_бота"]');
    links.forEach(link => {
      try {
        const url = new URL(link.href);
        const start = url.searchParams.get('start') || 'utm_ya';
        url.searchParams.set('start', `${start}_${clientID}`);
        link.href = url.toString();
      } catch(e) {
        console.error('ClientID append error:', e);
      }
    });
  });
</script>
```

Важно:

* замените `<ID_СЧЁТЧИКА>` на реальный ID счётчика (только цифры без кавычек);
* замените `t.me/имя_бота` на ваш реальный адрес бота.

---

## 9. Проверка работы

### Проверка сохранения CID

Перейдите по ссылке с  аккаунта который не зарегистрирован в боте:

```
https://t.me/<бот>?start=utm_ya_1234567890
```

В логах модуля появится:

```
Captured cid=***... for tg_id=...
```

### Проверка отправки событий

Выдайте себе триал или проведите оплату:

```
Trial event sent (status=200)
Purchase event sent (status=200)
```

### Проверка в Метрике

Через 10–15 минут данные появятся в разделе **Конверсии**.

## 10. Настройка Яндекс Директ

При создании рекламы укажите адрес вашей страницы/лендинга, подключите счётчик Метрики и добавьте целевые действия:

* Trial (выдан триал)
* Purchase (оплата подписки)

Назначьте цену цели — Директ будет оптимизировать кампанию под них.

---

## 11. Важная информация о модерации Яндекс.Директ

Если на вашем сайте явно указано, что вы продаёте VPN или демонстрируется функциональность VPN‑сервиса, реклама **не пройдёт модерацию**. Яндекс блокирует все объявления, которые напрямую относятся к VPN.

Чтобы кампания прошла модерацию:

* Создайте **отдельную страницу**, внешне не связанную с продажей VPN.
* Уберите любые упоминания VPN, прокси, обхода блокировок, анонимности и т.п.
* Продумайте, **под видом каких услуг** вы будете подавать свой сервис — включите фантазию. 

Если у вас ещё нет страницы — обязательно создайте. Главное правило: страница не должна содержать ничего, что может указать модерации на продажу VPN. Пользователи после перехода по ссылке уже попадут в бота, который объяснит всё остальное.
