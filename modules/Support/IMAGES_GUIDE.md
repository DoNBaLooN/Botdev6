# 📸 Инструкция по добавлению изображений для GigaChat

## 📁 Структура папок

Все изображения должны размещаться в папке `images/` с соответствующими подпапками:

```
images/
├── happ/           # Изображения для инструкций по HAPP
├── android_tv/     # Изображения для Android TV
├── steam_deck/     # Изображения для Steam Deck  
├── oculus_quest/   # Изображения для Oculus Quest
├── balance/        # Изображения для пополнения баланса
├── coupon/         # Изображения для активации купонов
└── refresh/        # Изображения для обновления подписки
```

## 🤖 Как GigaChat запрашивает изображения

GigaChat может использовать следующие команды в своих ответах:

### Отправить все изображения из папки:
```
[IMAGES:happ:all]
```

### Отправить конкретные изображения:
```
[IMAGES:happ:step1,step2,step3]
[IMAGES:android_tv:setup,qr_code]
[IMAGES:steam_deck:desktop_mode,download,permissions]
```

## 🚀 Как добавить новые изображения

1. Поместите изображение в соответствующую папку
2. Назовите его понятным именем (английскими буквами)
3. GigaChat автоматически сможет их использовать


### 💡 Советы по именованию

- **Папки**: короткие английские названия (android_tv, steam_deck)
- **Файлы**: понятные названия, описывающие содержимое
- **Избегайте**: пробелов, спецсимволов, кириллицы в именах файлов
