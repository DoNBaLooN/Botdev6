# VPN Support Bot - Руководство по интеграции

## 📋 Описание

Модуль бота технической поддержк### Для пользователей:
- **Создание тикетов поддержки** - просто отправьте сообщение боту поддержки
- **ИИ-помощник (GigaChat)** - автоматические ответы на типовые вопросы 24/7
- **Вызов оператора** - кнопка для связи с живым специалистом
- **Автоматическое управление тикетами** - один активный тикет на пользователя  
- **Просмотр статуса тикетов** через кнопки меню

### Для администраторов:
- **Управление тикетами** в групповом чате через топики
- **Просмотр информации о пользователе** из основной базы данных
- **Автоматическое уведомление** о новых тикетах и ИИ-ответах
- **Закрытие тикетов** через кнопки в чате поддержки
- **Мониторинг ИИ-активности** - все ответы GigaChat логируютсяbot . **Запускается автоматически** вместе с основным ботом, получает данные пользователей из той же базы данных. Название проекта и username основного бота настраиваются через переменные окружения.

## 🤖 Предварительная настройка

### 1. Создание бота поддержки

1. **Откройте Telegram** и найдите бота [@BotFather](https://t.me/BotFather)
2. **Отправьте команду** `/newbot`
3. **Введите название** вашего бота поддержки (например: "MyProject Support Bot")
4. **Введите username** бота (например: "myproject_support_bot")
5. **Сохраните токен** - он понадобится для настройки

### 2. Создание и настройка группы поддержки

1. **Создайте новую группу** в Telegram для технической поддержки
2. **Включите топики** в группе:
   - Откройте настройки группы
   - Включите "Топики" 
3. **Добавьте созданного бота** в группу как администратора:
   - Откройте настройки группы
   - Нажмите "Администраторы" → "Добавить администратора"
   - Найдите и добавьте вашего бота поддержки
   - Дайте ему все необходимые права администратора (в том числе управление топиками)
4. **Получите ID группы**:
   - Добавьте бота [@getmyid_bot](https://t.me/getmyid_bot) в группу !!ВАЖНО, ПОСЛЕ ТОГО КАК ВКЛЮЧИЛИ РЕЖИМ ТОПИКОВ!!
   - Отправьте команду `/id` в группу
   - Скопируйте ID группы (число вида `-1001234567890`)
   - После получения ID можете удалить @getmyid_bot из группы

### 3. Получение ID администраторов

1. **Откройте личный чат** с ботом [@getmyid_bot](https://t.me/getmyid_bot)  
2. **Отправьте команду** `/id`
3. **Скопируйте ваш ID** (число вида `123456789`)
4. **Повторите для других администраторов**, которым нужен доступ к управлению ботом поддержки

## 🚀 Быстрая настройка Support Bot - Руководство по интеграции

## 📋 Описание

Модуль бота технической поддержки для Solobot VPN проектов. **Запускается автоматически** вместе с основным ботом, получает данные пользователей из той же базы данных. Название проекта и username основного бота настраиваются через переменные окружения.

## 🚀 Быстрая настройка

### 4. Размещение модуля

Переместите папку `Support` в директорию `modules/` вашего основного бота:

```
Solo_bot-main/
├── modules/
│   └── Support/          ← Поместите папку сюда
│       ├── main.py
│       ├── config.py
│       ├── router.py
│       └── ...
├── bot.py
└── ...
```

### 5. Настройка переменных окружения

Создайте файл `.env` в папке `modules/Support/` со следующим содержимым:

nano .env
# Обязательные параметры
BOT_TOKEN=your_support_bot_token_here
SUPPORT_CHAT_ID=
PROJECT_NAME=Your Project Name
MAIN_BOT_USERNAME=your_main_bot_username
ADMIN_IDS=123456789,987654321
DEBUG=false
LOG_LEVEL=INFO
MAIN_BOT_INTEGRATION=True


### 6. Запуск

1. **Перезапустите основной бот:**
sudo systemctl restart bot.service  && sudo journalctl -u bot.service -f

2. **Бот поддержки запустится автоматически!** 🎉

### 8. Управление ботом поддержки

После запуска используйте команду `/support` в основном боте (только для администраторов):

- **🟢 Запустить** - запуск бота поддержки
- **🔴 Остановить** - остановка бота поддержки  
- **🔄 Перезапустить** - перезапуск бота поддержки
- **📊 Статус** - проверка состояния бота поддержки
- **⚙️ Настройки** - просмотр конфигурации

## 🔧 Архитектура

### Файлы модуля:
- **router.py** - Интеграция с основным ботом (команда /support) и автозапуск
- **main.py** - Основной файл бота поддержки
- **safe_integration.py** - Безопасная интеграция с базой данных основного бота
- **api_client.py** - API клиент для форматирования данных пользователей
- **support_handler.py** - Обработка тикетов поддержки
- **ai_response_handler.py** - Управление ИИ-ответами и режимами
- **gigachat_client.py** - Клиент для работы с GigaChat API
- **topic_storage.py** - Управление топиками в групповом чате
- **config.py** - Конфигурация бота поддержки

## ⚙️ Переменные окружения

### Обязательные:
- `BOT_TOKEN` - токен Telegram бота поддержки
- `SUPPORT_CHAT_ID` - ID группы/канала для технической поддержки

### Настройка проекта:
- `PROJECT_NAME` - название проекта (по умолчанию: "🔥McQueen Connection🔥")
- `MAIN_BOT_USERNAME` - username основного бота без @ (по умолчанию: "McQueenConnect_bot")

### Дополнительные:
- `ADMIN_IDS` - список ID администраторов через запятую
- `DEBUG` - режим отладки (true/false)
- `LOG_LEVEL` - уровень логирования (DEBUG/INFO/WARNING/ERROR)

## 🤖 Настройка ИИ-помощника (GigaChat)

Модуль поддерживает интеграцию с GigaChat для автоматических ответов пользователям.

### 1. Получение токена GigaChat

1. **Перейдите на сайт** [GigaChat](https://developers.sber.ru/portal/products/gigachat)
2. **Зарегистрируйтесь** или войдите в аккаунт
3. **Создайте новый проект** в личном кабинете "GigaChat API"
4. **Получите API ключ** для персонального доступа
5. **Скопируйте токен** - он понадобится для настройки

### 2. Настройка токена в .env

Добавьте следующие параметры в файл `.env`:

```bash
# GigaChat настройки
GIGACHAT_TOKEN=your_gigachat_token_here

# Настройка текстов для ИИ (опционально)
SUPPORT_SERVICE_NAME=Ваш VPN Сервис
SUPPORT_BOT_USERNAME=ваш_основной_бот (username)
SUPPORT_NEWS_CHANNEL=@ваш_новостной_канал
SUPPORT_VPN_PROTOCOL=VLESS
SUPPORT_APP_NAME_IOS=Ваше Приложение iOS (happ/v2ray)
SUPPORT_APP_NAME_ANDROID=Ваше Приложение Android (happ/v2ray)
```

### 3. Как работает ИИ-помощник

- **Автоматические ответы**: ИИ отвечает на сообщения пользователей в режиме реального времени
- **Контекст VPN**: Обучен на специфике VPN-сервисов и техподдержке
- **Эскалация**: Пользователи могут вызвать живого оператора кнопкой
- **Fallback ответы**: Если GigaChat недоступен, используются заготовленные ответы

### 4. Проверка работы GigaChat

После настройки:

1. **Отправьте сообщение** боту поддержки
2. **Проверьте логи** - должны появиться сообщения о работе GigaChat
3. **При ошибках** - проверьте токен и сетевое подключение

### 5. Отключение ИИ-помощника

Если не хотите использовать ИИ:
- Просто не указывайте `GIGACHAT_TOKEN` в .env
- Система автоматически будет работать без ИИ-ответов

## 🐛 Устранение неполадок

### Бот не запускается автоматически:
- Проверьте, что папка Support находится в modules/
- Убедитесь, что файл .env создан в modules/Support/
- Проверьте корректность BOT_TOKEN в .env
- Перезапустите основной бот

### Бот поддержки не отвечает:
- Убедитесь, что бот добавлен в групповой чат как администратор  
- Проверьте, что SUPPORT_CHAT_ID правильно настроен
- Убедитесь, что чат настроен как форум (включены топики)

### Данные пользователей не отображаются:
- Проверьте подключение к базе данных основного бота
- Убедитесь, что пути к модулям основного бота корректны
- Проверьте права доступа к файлам базы данных

### Команда /support не работает:
- Убедитесь, что вы администратор основного бота
- Проверьте, что ваш ID добавлен в ADMIN_IDS
- Перезапустите основной бот для применения изменений

### GigaChat не отвечает:
- **Проверьте токен**: Убедитесь, что GIGACHAT_TOKEN правильно настроен в .env
- **Проверьте интернет**: GigaChat требует стабильного интернет-соединения
- **Проверьте логи**: Найдите ошибки в логах бота, связанные с "GigaChat"
- **SSL ошибки**: Попробуйте перезапустить основного бота - часто помогает
- **Fallback режим**: Если GigaChat недоступен, бот продолжит работать с заготовленными ответами

### ИИ дает неправильные ответы:
- **Настройте переменные**: Убедитесь, что SUPPORT_SERVICE_NAME и другие переменные корректны
- **Обновите конфигурацию**: Перезапустите бота после изменения .env
- **Проверьте промпт**: В gigachat_client.py можно настроить системный промпт под ваш сервис
